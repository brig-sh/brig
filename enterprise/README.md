# Brig Enterprise

This directory holds Brig Enterprise, the Go module
`github.com/brig-sh/brig/enterprise`. It builds `enterprise/cmd/brig` from the
same core as Brig Community and adds `brig login`, `brig logout`,
`brig recordings` and the recording of a signed-in run. The Apache License 2.0
of the rest of this repository does not cover it.
[LICENSE](LICENSE) covers every file here, and it does not yet grant any
right to use, build or distribute them.
