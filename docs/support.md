# Support

## Ask a question

Open an issue: [github.com/brig-sh/brig/issues](https://github.com/brig-sh/brig/issues).
There is no other channel yet.

## File a bug

Open an issue and pick the bug report template. Include:

- The command you ran.
- The output of `brig version`.
- The output of `brig doctor`, which prints one line per check: brig (the
  build), host, virtual, runtime, boot, verify, profiles, secrets, brigd and
  image.

[Issues](../CONTRIBUTING.md#issues) in the contributing guide lists what else
helps: the runtime version, your environment, and the steps to reproduce.

If Brig or its runtime does not install or start, first make sure that your
platform is supported. See [Platform support](install.md#platform-support).

## Report a vulnerability

Follow [../SECURITY.md](../SECURITY.md) to report a security problem. It
sends the report through GitHub's private vulnerability reporting, so nothing
is disclosed before a fix exists. Do not open a public issue.
